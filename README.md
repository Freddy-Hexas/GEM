# 🎵 与GEM对话

这是一个基于 G.E.M. 邓紫棋（解解）歌词打造的聊天机器人。它的初衷很简单：当你输入一句话，它能从用最贴切的歌词与你对话。

这个版本是为直接运行而设计的，我们已经为你预先构建好了 ChromaDB 向量库。为了保持包体的轻量，在这个版本中我们移除了原始的训练脚本和庞大的歌词源文件，只留下了核心的灵魂供你使用。

## 📦 准备工作

本模型依赖 **Ollama** 来提供对话能力。在使用前，请务必完成以下三步：

1.  **安装 Ollama**：如果你还没有安装，请前往 [Ollama 官网](https://ollama.com) 下载。
2.  **下载模型**：打开终端运行 `ollama pull qwen3:8b`（这是默认配置的模型）。
3.  **保持大脑在线**：在运行程序时，**请确保 Ollama 服务正在后台运行**。
    * *Tips：通常安装后它会自动运行。如果你关闭了它，请在终端输入 `ollama serve` 来唤醒它。*

## 🚀 快速开始

在开始之前，请确保你本地已安装并运行了 Ollama。

```bash
# 安装必要的依赖环境
pip install -r requirements.txt

# 启动对话
python main.py
```

## 🛠️ 随心配置

如果你想调整它的性格或模型，可以在 `main.py` 中直接修改以下参数：

- `LLM_MODEL`: 默认使用 `qwen3:8b`（通过 Ollama 调用），你也可以换成你喜欢的模型。
- `EMBED_MODEL`: 默认采用 `BAAI/bge-m3` 以保证检索的准确性。
- `DB_PATH`: 预构建数据库的存放路径（默认为 `storage/chroma_db_smart`）。
- `TOP_K`: 决定了它每次翻阅多少句歌词来寻找灵感。

## 📂 目录结构

- `main.py`: 机器人的大脑，所有的核心逻辑都在这里。
- `storage/`: 存储着预先构建好的歌词向量库，是它记忆的来源。
